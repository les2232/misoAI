# Miso AI

Miso is a personal Raspberry Pi desk-buddy robot project.

## Current Status

Miso can currently run a simple Python heartbeat from the Raspberry Pi.

## Current Goal

Build Miso in small safe phases:

1. Local command-line personality
2. Simple local memory
3. Voice input and output
4. Web dashboard
5. Safe assistant tools
6. Cute physical robot features

## Safety Rule

Miso is a personal project. It should stay separate from work systems, institutional infrastructure, and private institutional data.
